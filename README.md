# Myanmar 2D Game

Playable **v0.0.3** prototype built with React + TypeScript + Phaser.

## v0.0.3
- Pixel-art-style generated character sprites
- Two-frame walking animation
- Three NPCs with different dialogue
- NPC interaction prompts
- Quest foundation with the village elder
- Coin collection quest: collect 5 coins
- Collectible leaf items + item counter
- Multiple buildings, fences, trees, water and village areas
- Collision boundaries
- Camera follow and smooth movement
- React/Zustand state shared with Phaser

## Controls
- WASD / Arrow Keys: move
- E: interact
- ESC: close dialogue

## Run
```bash
npm install
npm run dev
```
